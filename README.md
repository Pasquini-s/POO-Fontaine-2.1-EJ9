# POO-Fontaine-2.1-EJ9
Ejercitación 2.1 Ejercicio 9

En este codigo lo que logramos crear fue un carrito de compra con productos, de tal forma que creamos la clase de prodcuto con sus respectivos atributos de nombre y precio y luego aplicamos el encapsulamiento con el carrito de compras con el arraylist de productos.
Luego definimos métodos para que los productos tengan un nombre y que no sea vacío y un precio que no sea negativo.
Después nos enfocamos en el codigo del carrito de compras definiendo los métodos para agregaar un producto que no sea nulo, y calcular el total sumando todos los productos agregados.
Por último creamos el método mostrar detalle, en el cual, mostraremos formalmente el resumen de compra y verificaremos si el carrito esta vacío o, por medio de un bucle , los productos seleccionados con sus respectivos precios y precio final.

Al finalizar el código creamos 3 productos diferentes con nombres y precios para agregarlos, y luego creamos el carrito de compras para añadir dichos productos y que nos muestre el detalle de la compra.
